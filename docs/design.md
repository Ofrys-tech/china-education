# Дизайн

## Концепция

**Тихая роскошь международного образования.** Глубокий чёрный, металлическое золото и тёплый ivory. Крупная антиква, много воздуха, тонкие золотые линии и один сильный жест на экран. Ощущение частного международного дома, а не агентства с градиентами.

Ключевые образы:

- чёрный `#0c0c0d`, золото `#c8a45c`, ivory `#f7f3ea`;
- монограмма ADLAS: буква A, орбита и четырёхлучевая звезда — без флагов, кепок и национальных символов;
- Prata для заголовков и логотипа, Golos Text для интерфейса;
- круговая «мировая печать» в hero: орбиты, страны, золотой центр;
- тонкие линии-разделители, крупные цифры, моноширинные индексы;
- сгенерированные золотые эмблемы: лавр (стипендии), орбитальная сфера (сообщество), ключ (жильё).

Это не финальный бренд-гайд; меняйте через токены и `adlas.css`, обсуждайте на `/styleguide/`.

## Тексты

Весь UI-копирайт — в `src/i18n/en/**` по разделам. Страницы только собирают блоки. Контент программ/вузов/FAQ — JSON в `src/content`.

## Слои CSS

1. `tokens.css` — значения.
2. `global.css` — сброс, layout, исторические компоненты, формы, FAQ.
3. `adlas.css` — бренд-слой: hero, карточки, направления, каталог, success-карточки, футер, адаптив.

Порядок важен: `adlas.css` подключается после `global.css` в `BaseLayout`.

## Адаптив и доступность

- Проверять 390px и 1440px; никакого горизонтального скролла страницы.
- Навигация сворачивается в меню до 1320px, мобильное меню — полноэкранное.
- Контраст: обычный текст ≥4.5:1, крупный ≥3:1. Золотой текст на ivory — только `--color-gold-deep`.
- Фокус видимый, меню: `aria-expanded`, Escape, блокировка скролла, возврат фокуса.
- Форма: labels, `aria-invalid`, `aria-describedby`, `aria-live`.
- Floating WhatsApp скрывается над hero, формой и футером, чтобы не закрывать контент.
- `prefers-reduced-motion` отключает reveal и орбиты.
