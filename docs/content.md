# Контент

Контент отделён от шаблонов и валидируется Zod на сборке. Ошибка в схеме = упавший build, а не битая страница.

**Весь копирайт сайта — английский.** UI-строки (заголовки, кнопки, подписи, ошибки) живут в `src/i18n/en/**`; JSON ниже — только контент программ, вузов и FAQ. Не дублируйте UI-текст в JSON и не хардкодьте его в шаблонах.

## Где что лежит

| Коллекция      | Папка                       | Файл = `id`                             | Использование                       |
| -------------- | --------------------------- | --------------------------------------- | ----------------------------------- |
| `programs`     | `src/content/programs/`     | `bachelor.json` → `/programs/bachelor/` | главная (6), каталог (все)          |
| `universities` | `src/content/universities/` | `tsinghua.json`                         | главная (6), `/universities/` (все) |
| `faq`          | `src/content/faq/`          | `cost.json`                             | главная (`home: true`), `/faq/`     |

Схемы: `src/content.config.ts`.

## Программа

```json
{
  "title": "Бакалавриат в Китае",
  "degree": "bachelor",
  "summary": "1–2 предложения для карточки и meta description.",
  "duration": "4 года",
  "languages": ["zh", "en"],
  "tuition": "¥16 000–30 000 / год",
  "overview": ["Абзац 1", "Абзац 2"],
  "fitFor": ["Кому подходит"],
  "outcomes": ["Что получит студент"],
  "timeline": [{ "step": "За 10–12 месяцев", "text": "Что делаем" }],
  "faq": [{ "question": "Вопрос?", "answer": "Ответ." }],
  "featured": true,
  "order": 1
}
```

- `degree`: `language | bachelor | master | mba | phd | short`.
- `languages`: `zh | en`.
- `order` уникален, определяет сортировку.
- `featured` делает карточку тёмной на главной.
- `tuition` — всегда ориентир, не оферта.
- `summary` попадает в `<meta name="description">` и OG; 120–180 символов.

Новая программа: создайте JSON → `npm test` → `npm run verify`. Страница и ссылки появятся автоматически.

## Вуз

```json
{
  "name": "Zhejiang University",
  "nameZh": "浙江大学",
  "city": "Ханчжоу",
  "type": "public",
  "founded": 1897,
  "strengths": ["Инженерия", "IT", "Бизнес"],
  "language": "Английский / китайский",
  "scholarship": true,
  "note": "1–2 предложения о профиле и конкурсе.",
  "officialUrl": "https://www.zju.edu.cn/english/",
  "featured": true,
  "order": 4
}
```

- `officialUrl` обязателен, HTTPS, проверяется тестом на уникальность.
- `note` не должен звучать как реклама или гарантия.
- Не добавляйте вуз, если не готовы проверить ссылку и требования.

## FAQ

```json
{
  "question": "Сколько стоит учёба?",
  "answer": "Развёрнутый ответ на 2–4 предложения.",
  "category": "money",
  "order": 1,
  "home": true
}
```

- `category`: `admission | money | language | life | documents`.
- `home: true` — показывать в блоке на главной (нужно ≥5).
- Вопрос заканчивается `?`; ответ ≥120 символов (проверяется тестом).

## Тон и факты

- Спокойный, конкретный, без «уникальных возможностей» и «гарантированного будущего».
- Всегда разделяйте: что делаем мы / что решает вуз / что зависит от консульства.
- Не выдумывайте отзывы, имена, партнёрства, статистику, контакты.
- Стоимость и дедлайны — с оговоркой «ориентир, зависит от вуза и года».
- Медицина/право/инженерия — отдельно проверяйте признание в стране студента.
- Юридические формулировки и политика конфиденциальности требуют проверки перед запуском.

## SEO

- `title` страницы формируется в `BaseHead`: если нет названия бренда, добавляется `— ChinaPath`.
- `description` — из frontmatter/контента; не дублируйте её на разных страницах.
- Один `<h1>` на страницу (проверяет `check:html`).
- Внутренние ссылки — только через `withBase`.
- Служебные страницы — `noindex` + исключение из sitemap.

## Проверки

```bash
npm test                 # целостность JSON, уникальность order/url, placeholder-маркеры
npm run verify           # схема Zod на build + HTML
```

Placeholder-маркеры (`TODO`, `lorem ipsum`, `[insert`) в видимом тексте запрещены: `check:html` падает.
